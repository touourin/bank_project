# 模型配置

`.env` 中现有模型地址、模型名和密钥保留，配置模板在 `.env.example`。密钥使用 `SecretStr` 读取并由 Git 忽略。

第二步使用独立的 `alignment/model_client.py` 调用 OpenAI 兼容 JSON 接口，支持 DashScope。小表通常一次调用，宽表先制定概览，再按最多 32 列一批、最多 3 批并发解释；分批和校验由 `alignment/interpretation.py` 负责。仅解释字段含义与实体分组，不选择本体节点；节点及得分通过独立 retrieve 适配器获取。

仅在发起分析后发送结构及少量截取样例；启动和第一步不消耗模型额度。字段批次共享整表含义与分组，输入按大小限制、结果按完整性校验。输出截断或字段漏回、重复、越界时自动拆小受影响批次，网络临时故障有限重试；失败报告批次和列序号，凭据及原始错误不返回浏览器。宽表调用次数及费用随列数增长，不随全表行数增长。详见 [第二步说明](alignment.md)。
