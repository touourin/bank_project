## 初始核查结论（补齐前）

当前实现迁入了索引及问答主流程、消歧核心引擎，并新增 DB 图适配、人工审核和 BOID 挂载，但不是原应用的完整等价迁移。此前“完整迁移”的表述不准确。测试通过证明了所测链路可运行，不能证明原配置和原页面行为已全部保留。

必须区分原仓库中的两条路线：

- `unified-search-app/` 是独立应用，锁定 GraphRAG **2.5.0**，包含企业图谱页面、数据集业务提示词、通用文档导入、问答和离线消歧结果查看器。
- `packages/graphrag/` 的项目版本是 **3.1.2**，另有消歧引擎、聚合前记录导出及实验对比工具。不能只复制其引擎文件，就认为这些接入步骤也已经接好。
