# 客户标签与客户旅程字段说明

对应 schema 1.2、2026-09-17 的默认 mock 样例。Excel 查阅版见 [字段说明.xlsx](字段说明.xlsx)。

这是当前样例的字段说明快照；`make mock` 不自动重建该文档。schema 或样例规则变化后，应同步更新 Excel 与本说明。源规则仍以 `configs/bank/schema.json` 为准。
