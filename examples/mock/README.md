## 生成与校验

在项目根目录运行：

```bash
make mock
make mock-check

# Python 3.9+ 即可运行，无需安装第三方库或启动服务
python3 scripts/generate_mock.py --customers 1000 --as-of 2026-09-17 --seed 20260917
python3 scripts/validate_mock.py
```

默认生成 1,000 个客户。相同规则版本、schema、参数生成相同文件字节。
`make mock` 更新两张 CSV 和 manifest；Excel 是配套查阅快照，重新生成或修改规则后须同步刷新。
生成不启动 FastAPI、不调用 LLM、不写入数据库；应用业务接口仍是框架占位。

## 当前模拟规则

- **客户差异**：信息科技、精密制造、商贸、供应链、食品、医疗科技六类行业；上海浦东、闵行、嘉定及苏州、杭州、宁波六个地区。名称、经营范围、地区与办理支行相互对应。
- **规模关联**：三档合成企业规模，员工数、注册资本和存款处于相应区间；实收资本不超过注册资本。规模名称和分类码仍是测试约定，不声称符合银行正式划分规则。
- **业务分布**：前 20 户用于保证场景覆盖；其余客户按合成权重分配存款理财、贷款未结清、贷款结清、授信拒绝、一般结算场景，再独立组合签约、代发和外部事件。权重用于测试，不代表银行实际客户分布。
- **日期差异**：企业成立、建档、开户日期各不相同。账户使用在开户后，次要账户销户后不再发生该账号的业务，主账户仍保留。新开户客户的业务记录更少。
- **授信与还款**：每户至多一笔申请、一笔有效授信和一笔放款；批复为申请金额的 60%～100%，使用额度为批复金额的 25%～90%。通过客户有 2～5 次还款，已结清客户最后一次归还剩余本金；每笔都核对当时余额。申报、批复、签约、放款、还款日期有先后顺序。
- **代发工资**：部分客户连续多月代发，最多 12 个月；按截至日只保留已发生记录。代发员工为同一组、人数不超过从业人数，金额随行业、月份和模拟奖金变化。一人一笔，近 12 月笔数按各月人数累加，人数按这组员工去重。
- **存款与理财**：允许零存款客户；有资金的客户可组合活期、1～3 笔不同期限的定期、不同理财产品。存款事件记录本版期末持有本金，定期尚未到期；其金额合计与标签余额一致。这不是完整资金进出流水。
- **外部事件**：工商变更、融资、招投标、正面/中性/负面舆情按客户组合；少量客户有上市事件。融资标签取该客户最新融资事件；上市标志与上市事件一致。本版预警标志仅与模拟负面舆情关联，不是银行风控规则。
- **两表关联**：旅程 `CUST_ID` 等于标签 `cust_ind`，建档 JSON 内的客户号也相同。注册资本、统一社会信用代码、成立日期、贷款余额、可用额度、代发汇总、签约标志与对应事件核对。
- **分类与标识**：未取得银行码表的机构、行业、企业规模等分类仍使用 `MOCK_`；合成名称保留「模拟」标记。客户号、账号和证件占位值不用于真实有效性测试。
- **未模拟部分**：未知统计口径的部分指标仍为 0 占位或空值，字段说明页逐项注明。日均余额采用独立模拟系数，不能从这批有限事件重算；未提供完整交易流水或财报数据。

## 格式与精度

- CSV 为 UTF-8 带 BOM、逗号分隔、LF 换行；只有一行英文表头。读取使用 `encoding="utf-8-sig"`。
- 旅程保持原有八列：`DT,ROWKEY,EVT_CLASS,EVT_TYPE,CUST_ID,OCCUR_DT,KEY_FLAG,PROPERTIES`。
- 编号、账号、码值和 `YYYYMMDD` 日期均按文本读取；账号保留前导 0。
- `PROPERTIES` 是 JSON 对象文本；先解析 CSV，再解析 JSON。金额使用十进制数值，Python 可用 `json.loads(text, parse_float=Decimal)` 保留精度。
- 标签 `DECIMAL(26,8)` 固定 8 位小数，金额本版按 CNY 元，比例为 0～1。CSV 保留完整十进制文本。
- Excel 中金额和整数使用数值单元格；若某值超过 Excel 可安全保存的精度，则保留为文本。已逐格核对与 CSV 一致。
- CSV 空单元格表示未提供；JSON 的 `""` 是显式空字符串，省略键表示未提供该属性。

## 沿用的字段约定

1. `YWJC0017`、`YWJC0018` 为“未定义1”“未定义2”，不映射到外汇代客、国内证业务。
2. 账户类型允许空字符串；复合授信申报的授信品种为非必填，本版省略。
3. 舆论属性统一为舆情属性；未结清还款保留授信品种，结清还款保留贷款品种。
4. 代发签约保留 `账号`，代缴税费签约的经办机构沿用空字符串。
5. `snd_bl_cust_sign_ind`、`pyrl_sign_dt` 的字段名与中文含义尚待确认，保留源名并留空。
6. 银行未说明的属性必填性不擅自设为必填。字段名、类型与说明源于原表，模拟约定单独标注。

## 校验

校验字段、精度、日期、主键、两表关联、事件字典、JSON 类型以及上述场景的金额汇总。
另外按时间顺序校验开户与销户、代发签约、授信申报与批复、逐笔还款和结清状态。
校验器描述这版合成数据的一致性，不代替银行业务规则。

源结构来自《上海银行数据表结构参考.xlsx》的 `CCM_C_CUST_FLAG_INFO`、`E_CRM_C_CUST_TOUR_EVT_SUM` 和「客户旅程数据样例」page。
源需求来自《营销助手数据需求.xlsx》的「客户标签」「客户旅程」page。原始工作簿不随项目分发。
