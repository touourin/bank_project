# 五表可用性修正版

客户标签1,000行、155列；客户旅程16,700行、8列；征信21,619行、98张来源表；工商8,324行、39张来源表；交易流水539,534行、103列。

交易流水完整 Excel 为本地生成的大文件，不随 Git 仓库分发；生成器、字段规则和校验脚本随代码提交，重建前需准备已核对的源字典 schema，见 `docs/source-mock.md`。上面的行数描述本地完整数据集。

数据均为虚构测试数据。完整schema字段保留，银行未提供的码表采用说明页中逐字段定义的测试码。
征信、工商已按原数据字典恢复为“一张来源表一个 Sheet”，不再将不同业务表纵向拼成一张稀疏宽表。征信每张来源表包含5–96个业务字段，工商包含8–46个业务字段；每张表另外保留1列source_row。
两份文件都包含“目录说明”和“数据说明”页面。目录列出来源表名、业务说明、记录数和业务字段数；数据页第1行为字段名。在“数据说明”筛选来源表名即可查看该表的中文字段说明、当前类型、原字段/原类型及原字典位置。
Sheet名承载原source_table，Sheet名与source_row共同定位拆分前的原始记录。相同证件号码出现在报告、账户、查询记录等不同来源表中，用于关联这些记录，不应因此删除业务明细或不同含义的字段。
拆分以各份现有工作簿为输入，没有重新生成数据，也没有将桌面版本与项目版本互相覆盖。逐来源表核验了全部记录、字段值、空值、文本/数字类型、数字/日期格式和字段说明。全空但原字典定义的字段也继续保留。
工商的 AGECLEAN、FOCUSNUMBER 统一为 INT，EXECMONEY、REGCAP、SUBCONAM 统一为 DECIMAL(26,8)。同名字段因原始类型不同产生的五对列已合并，原字段类型及来源保留在“数据说明”页；不同业务含义但数值相同的列继续保留。
客户标签与源数据包expected/customer_tags.csv完全一致，不再沿用旧版日均估算和零结算统计。
证件与账号按文本保存；金额按schema存储。日均金额按分四舍五入后存为DECIMAL(26,8)。
普通企业存款观察窗口为近12月，年日均从当年1月1日计至快照；贷款年日均从放款/还款事件逐日计算。
个人征信保留缺失与不适用空值。原字典可空关闭/结案日期即使标注PK，也不生成虚假的关闭日期；规范化测试键的调整在说明页逐字段注明。
股东出资以企业为组汇总；多股东明细的测试唯一键增加SHANAME，原字典字段不删除。
客户旅程中的MOCK_FX_SIGN、MOCK_LC_SIGN、MOCK_CREDIT_SIGN为已定义测试事件，正式银行事件码仍需映射。
M01及数据值中的“模拟”占位文字已清除。技术主键的MOCK_前缀保留以维持跨表关联。

之前的数据修订校验包括字段/类型、主键、明细与汇总、状态与日期、代理人证件、股东出资、财务勾稽、借贷方向、冲正及逐笔余额连续性；本次拆表额外做了拆分前后全量一致性核验。

本次只更新本地文件，没有写入数据库，也没有改动已导入的历史批次或银行原始数据字典。当前接入层每批最多30张表，98/39张表的完整工作簿暂不能直接作为单批导入；后续需适配选表或分批接入。“目录说明”和“数据说明”可由接入层的“跳过说明页”选项跳过。
