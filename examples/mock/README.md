完整明细保存在 `来源明细/征信明细.xlsx`（98张来源表、21,619条记录）和 `来源明细/工商明细.xlsx`（39张来源表、8,324条记录）。来源表结构、字段说明与 source_row 保留；人员值按上述修订同步。主文件的 source_refs 指向原 Sheet 与 source_row。做账户、股东或交易关系图时仍应使用明细，不把汇总行当成明细。
